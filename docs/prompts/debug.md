# 任务：调试报错

## 使用场景
代码编译失败、运行崩溃、功能异常时使用。

## 模板

```text
【项目宪法】
（粘贴 docs/CONTEXT.md）

【已实现接口】
（粘贴 docs/API.md 中相关的部分）

【问题描述】
（一句话说明要解决什么问题）

【完整报错信息】
（粘贴完整的错误信息，不要截断）

【相关文件】
（粘贴出问题的文件完整代码，标注路径）

【我尝试过的】
（列出已经试过的方案，避免 AI 重复建议）

【请求】
请分析报错原因，给出：
1. 根本原因（为什么错）
2. 修复方案（改哪个文件、哪一行、怎么改）
3. 修复后的完整代码
4. 是否需要同步修改其他文件
```

## 示例

```text
【项目宪法】
（CONTEXT.md 全文）

【已实现接口】
（API.md 中 Course、TimePlace 相关部分）

【问题描述】
Course.fromJson 解析时报类型错误

【完整报错信息】
type 'Null' is not a subtype of type 'String' in type cast

【相关文件】
// lib/models/course.dart
（粘贴完整代码）

【我尝试过的】
- 检查了 JSON 数据结构，name 字段确实存在
- 试过给 name 加 `?? ''` 兜底

【请求】
请分析报错原因，给出修复方案和完整代码。
```

## 调试要点

1. **完整粘贴报错**：不要只给最后一行
2. **提供相关文件**：报错涉及的所有文件
3. **说明已尝试的方案**：避免 AI 重复
4. **说明环境**：Flutter 版本、依赖版本（如果相关）
5. **一次只解决一个问题**：不要堆多个 bug
