# 提示词库（prompts）

> 本文件夹存放与 AI 协作的提示词模板。
> 每次生成代码前，从对应文件复制提示词，配合 `base.md` 使用。

---

## 使用流程

### 1. 每次任务前

1. 打开 `base.md`，复制"通用前缀"
2. 把 `docs/CONTEXT.md` 内容粘贴到前缀的"项目宪法"位置
3. 把 `docs/API.md` 内容粘贴到"已实现接口"位置
4. 从 `docs/PROGRESS.md` 复制当前进度
5. 打开对应任务的提示词（如 `01-models.md`），复制"任务"部分
6. 拼成完整提示词，发给 AI

### 2. 拿到 AI 输出后

1. **先 review**，检查是否符合规范
2. 保存代码到项目对应路径
3. 让 AI 生成接口清单，粘贴到 `docs/API.md`
4. 更新 `docs/PROGRESS.md`，勾掉已完成项
5. 提交时 commit message 注明来源

## 使用建议

1. **一次一个模块**：不要一次让 AI 生成 10 个文件
2. **先复述后生成**：在提示词末尾加"开始写代码前，先用 5 句话复述你的理解"
3. **更新 API.md 后再进行下一个**：确保契约一致
4. **遇到截断说"继续"**：AI 输出长代码会中断
5. **调试时完整粘贴**：报错信息 + 相关文件一起给
