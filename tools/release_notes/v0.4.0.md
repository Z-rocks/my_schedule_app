## 校园助手 v0.4.0

### 首个 iOS 版本（代码就绪，安装包需在 Mac 上打）

iPhone 上现在也能用了：登录教务系统、同步学习通的课程 / 作业 / 考试、课表、作业提醒都在。

**这次 Release 里没有 ipa**：iOS 包必须在 macOS + Xcode 上构建（`flutter build ipa`），当前开发机是 Windows 打不了。iOS 侧工程配置、原生桥、通知权限、ATS 放行都已写好并提交，打包步骤见 `docs/iOS.md`，在 Mac 上一条命令出包。

iOS 版这次的取舍：

| 功能 | iOS | 说明 |
|---|---|---|
| 教务系统登录（校内 / 校外二维码） | ✅ | 校外登录照样能存二维码到相册、拉起微信扫一扫 |
| 学习通课程 / 作业 / 考试 | ✅ | 与 Android 同一套插件 |
| 作业提醒 | ✅ | 系统本地通知，App 没打开也会响 |
| 到点前查作业状态 | ❌ | iOS 不允许后台起引擎查接口，提醒以排期时的快照为准 |
| 桌面小组件 | ❌ | 这次不做，设置页对应入口已隐藏 |

### 检查更新会按平台取包

以前「检查更新」只看 Release 里有没有 APK。现在会先看自己是什么设备：

- **Android**：照旧按 CPU 架构挑裁剪包（arm64 / armv7 / x86_64），挑不到再用通用包
- **iOS**：只认 `.ipa`，绝不会去下 Android 的 APK；没有 ipa 时弹窗说明并给出 Release 页面
- 本平台这次没传安装包时，弹窗会说明并给出 Release 页面，不会"点了没反应"

### 安装包

这次 Release 挂四个 Android 包（四个包共用同一个 versionCode，任意一个都能覆盖安装，覆盖安装不丢数据）：

| 文件 | 适用 |
|---|---|
| `app-arm64-v8a-release.apk` | 近几年的手机（推荐，最小） |
| `app-armeabi-v7a-release.apk` | 较老的 32 位手机 |
| `app-x86_64-release.apk` | 模拟器 |
| `app-release.apk` | 通用包（识别不出架构时用，最大） |

### 其它

- 设置页按平台隐藏了用不了的东西（小组件、精确闹钟、完整校验）
- iOS 上「检查更新」不再引导去下 APK
