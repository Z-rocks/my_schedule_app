## 校园助手 v0.3.4

### 更新时不再下 58MB 通用包

之前点「检查更新」，不管什么手机都会下载通用安装包（约 59MB），哪怕你的手机只需要其中一种架构。现在会先看手机的 CPU 架构，只下对应的裁剪包：

| 机型 | 更新包大小 |
|---|---|
| 近几年的手机（arm64-v8a） | 约 23MB |
| 较老的手机（armeabi-v7a） | 约 21MB |
| 模拟器（x86_64） | 约 25MB |
| 识别不出架构 / 对应包缺失 | 回落到通用包（约 59MB） |

裁剪包只认精确匹配——不会把 arm64 的包发给老机型，装不上比多下点流量更糟。

### 安装包之间可以随便换了

以前分架构包的版本号和通用包不是一套编号，装过其中一个之后再装另一个会被系统拒绝（提示"版本降级"）。这次统一了编号，Release 里四个包**任意一个都能覆盖安装**，从哪个换成哪个都不会失败。

覆盖安装照旧不丢数据：学期、课程、插件登录状态都保留。

### 说明

- 功能上与 v0.3.3 一致，本次只改分发方式，没有新功能也没有行为变化
- 如果你之前是手动从 Release 页面下载安装的，这次也可以继续手动下——四个包都能直接用
